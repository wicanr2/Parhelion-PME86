# `SYSTEM.PME.86` 開頭那 512 個位元組

檔案最前面看起來是一堆沒有規律的常數：18 個非零的 word，後面一路是零，
到 `0x0100` 之後才零星再出現幾個，接著才是程式碼。那些值不是指令。

```
偏移  0x00: 3a04 0000 0c9b 0000 00e6 0026 0028 003e
偏移  0x10: 02fe 185a 1865 1870 1874 0306 1281 11bc
偏移  0x20: 11ba 11af 0000 0000 …
```

結論先講：**那是直譯器自己的初始資料。** 載入器把檔案開頭那 512 個位元組
原封不動搬進**資料段的同一個偏移**，然後把 `0x1d56` 起的 dispatch 表搬到
映像偏移 0 蓋掉它。所以它在程式碼段裡看不到——它只在資料段裡活著，
而且活到系統關掉為止。

> [取指令與分派](../10-interpreter/dispatch-and-threading.md)

## 怎麼確定的

把系統跑起來，在**第一條 p-code 執行的那一刻**把資料段前 512 個位元組
與磁碟上那 512 個位元組逐 word 比：

```
檔案開頭那 512 個位元組裡，非零的 37 個 word 有 37 個原封不動搬進資料段
```

一個不差。零的那些是留給執行期狀態的空格——`IPC`、`MP`、`E_Rec` 這些
由 bootstrap 在交棒之前填進去。

只有一格例外：`0x06` 在檔案裡是 0，在記憶體裡是 `0x0140`，
那是 bootstrap 填的開機參數區位址。

## 裡面是什麼

那 37 個 word 是**直譯器對作業系統的自我介紹**，加上幾個初值。
作業系統本體是 p-code 寫的，它需要知道直譯器的狀態放在哪、
以及要叫直譯器做事時該跳到哪裡：

| 偏移 | 是什麼 |
|---|---|
| `0x08` | SYSCOM 的位址（`0x00E6`）|
| `0x0A` | 局部資料基底（`MP + 8`）在狀態區的偏移 |
| `0x0C` | 全域資料基底（`Env_Data + 8`）的偏移 |
| `0x0E` | 目前 `E_Rec` 的偏移 |
| `0x12`–`0x18` | 四個原生回呼的進入點（`185A`／`1865`／`1870`／`1874`）|
| `0x1A`–`0x22` | 其他直譯器碼位址 |
| `0x44` | byte sex 旗標的初值（1 ＝ 與主機相同）|
| `0xE6` 起 | SYSCOM：裝置數與參數 |
| `0x140` 起 | 開機參數，以及最外層那個框的 `MSSTAT`／`MSDYN` |
| `0x178`／`0x17A` | 全域變數 1 指向 SYSCOM |

那四個回呼位址在直譯器裡長這樣（`0x185A` 起）：

```
185a: mov bp, sp
185c: mov di, [bp+4]
185f: call 0x1791      ; SIGNAL
1862: lret 2
1865: mov bp, sp
1867: mov di, [bp+4]
186a: call 0x1878      ; 中斷來了：SIGNAL 掛在那個向量上的號誌
186d: lret 2
1870: call 0x1837      ; 關中斷
1873: lret
1874: call 0x183c      ; 開中斷
1877: lret
```

`lret` 表示它們是**給遠呼叫用的**——作業系統從 p-code 那一側經 `NAT`
跳進來，做完 `lret` 回去。這正是「p-code 的世界」與「機器碼的世界」
之間那道門。

## 為什麼是這個做法

一份**位置固定、在檔案最前面**的資料，載入器只要無腦搬過去就好，
不必認得裡面任何一格。直譯器換版本時只要改自己的表，載入器不用動。

而它與 dispatch 表共用那 512 個位元組也不是巧合：
**那塊空間在載入之後對程式碼段沒有用**（表要搬到偏移 0 才能讓
`jmp word ptr cs:[di]` 不必帶位移），所以拿來擺一份要複製出去的資料，
一個位元組都不浪費。

## 邊界

- `0x3a04` 與 `0x0c9b` 這兩格沒有解。值域上一個接近檔尾、
  一個落在錯誤處理與定址助手之間，但沒有追到使用端。
- `0x12` 之後那些位址是**這一份直譯器的**。重做一台的時候它們沒有對應物——
  作業系統只在 `NAT` 呼叫時用得到，而 `NAT` 要一台 8086 才做得到。
- 「37 個 word 一個不差」是實測（`TestInterpreterDataComesFromItsOwnHeader`）；
  「所以它是初始資料」是對那個實測最直接的讀法。
