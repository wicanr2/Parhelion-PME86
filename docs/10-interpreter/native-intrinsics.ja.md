# セグメント 1 に埋め込まれたネイティブ手続き：p-code と機械語の境界

[English](native-intrinsics.en.md) ｜ **日本語** ｜ [繁體中文](native-intrinsics.md)

オペレーティング・システム本体は p-code で書かれているが、それでもメモリを動かし、
ディスクに触れ、割り込みを止める手段は要る。IV.0 マニュアルは p.66 で一文だけ触れる——
セグメント 1 の手続きコードはインタプリタ内に直接実装されている**かもしれない**。
この稿はその一文を開く——**それはこの機械における「p-code でないもの」の完全な一覧である**。

## 境界はインタプリタ自身が引く

セグメント 1 へのセグメント間呼び出しでは、`CXG` がまず表を引く（@0x13F4、`SCXG1` も
同じ道）：

```
13f4: cmp bp, 1            ; セグメント番号は 1 か
13f7: jnz 一般経路
13f9: mov di, [si]         ; 手続き番号を覗く（進めない）
13fb: and di, 0FFh
13ff: cmp di, 2Fh
1402: jg  一般経路         ; > 47 → 埋め込み実装は無い
1404: shl di, 1
1406: mov di, cs:[di+1F56h]
140b: cmp di, 0
140e: jz  一般経路         ; この枠が 0 → 埋め込み実装は無い
1410: inc si
1411: jmp di               ; そのまま機械語へ跳ぶ
```

`0x1F56` から 48 枠、手続き番号で引く。**非ゼロは 33 枠、相異なるアドレスは 26 個**
（7 対が同じルーチンを指す）。外れたら通常のセグメント間呼び出しに戻り、
セグメント 1 の中の p-code を探しにいく。

つまりこの表こそが境界である——**表に載っているものはホストの仕事、それ以外は p-code。**

## デバイス族は実は 1 本

18／19／31／33／34／36 はすべて同じコードに落ち、`0x2AA0` に書き込むモード・バイトだけが
違う：

| モード | 誰 |
|---:|---|
| 1 | `UNITREAD` |
| 2 | `UNITWRITE` |
| 3 | 手続き 31／33 |
| 4 | デバイスの完了待ち |
| 8 | デバイス状態の問い合わせ |

引数ブロックはインタプリタ・イメージの `0x2AA0`–`0x2AA8` にある——モード、unit、
バッファ・アドレス、長さ、ブロック番号、mode。スタック上を上から下へ辿る順序は
`mode、block、length、バッファの（基底, オフセット）、unit`——すなわち Pascal の
`UNITREAD(unit, buf, length, block, mode)` を左から右へ積んだ形だ。

完了すると結果は `IORESULT`（`ss:0E6h`、@0x2B3B の第 1 命令で 0 に消される）へ書かれる。

## 噛みつく 2 つの細部

**`ss:0E6h` は二役を担う。** `IORESULT` であると同時に `MSPROC` の上位バイトでもある
（@0x160F がタスク状態の保存時に `TIB+12h` へ合成する）。だからインタプリタがこの枠を
書くのはタスク切り替えのときだけだ——呼び出しのたびに書けばデバイスの結果を潰す。

**復帰先はいつも手続き番号の次とは限らない。** `SCXG` は @0x0545 の入口で `si` を
`ss:24h` に退避するが、その時点で指しているのは**手続き番号**である。@0x1410 の
`inc si` はそのあと、機械語へ跳ぶ直前に起きる。多くのネイティブ手続きは自分でもう一度
退避するので（`MOVELEFT` は @0x192C）手続き番号の次に復帰するが、
**自分で退避しない数本は手続き番号そのものに復帰する**——そしてそのバイトが次の命令として
実行される。手続き 4 の番号は `04`、ちょうど `SLDC 4` にあたる。

## 境界

- 「非ゼロ 33 枠、相異なるアドレス 26 個」はイメージのバイトを直接数えた結果で、堅い。
- 「内容」欄のうち「読了」の付いた行は一命令ずつ読み、実際の対向実行で検証済み。
  付いていない行は表に載っていることしかわかっていない。
- 引数の順序はすべて `pop` の順から読み取り、[自己起動](../30-remake/specs/03-boot.md)で
  オリジナルと逐一対向実行して確認した。
