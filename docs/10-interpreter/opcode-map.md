# 256 格對照表：IV.0 官方助記符 × PME.86 dispatch 表

表由 `tools/analyze-dispatch.py --table` 產生，來源是 `tools/routines-86.json`
（`SYSTEM.PME.86`，sha256 `fe427aa6…`）與 `tools/iv0-opcodes.json`
（SofTech《UCSD p-System IV.0 Internal Architecture Guide》Appendix VI.B）。

> 延伸閱讀：[取指令與分派](dispatch-and-threading.md)｜[定址](addressing.md)

「常式」欄是**檔案偏移**，不是執行期位址。指令數是逐支反組譯到第一個無條件轉移為止
的條數，上限 80。

助記符與實作對得上的地方不只是編號。以下十幾支的內容本身就印證了名字：
`IXP` 用一次 `div` 同時得到商與餘數、`DVI` 是 `idiv`、`BNOT` 是 `not` 後 `and 1`、
`SBR` 翻掉符號位再落進 `ADR`、`XJP` 讀 case 表的上下界、`CSP` 比長度後 `rep movsb`、
`LCO`／`LDC`／`LDCRL` 都加常數池基底、`RPU` 逐格彈出 Mark Stack。
